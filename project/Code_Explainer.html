Colors.java

src/Colors.java
This file defines ALL the colors used in our entire application. Instead of writing color codes like "#2F3A1D" everywhere in our code (which would be messy and hard to change), we store them in one place as named constants. If we ever want to change a color, we change it here ONCE and it updates everywhere.
Why does this file exist? Imagine you have a 500-page book and every page says "the headers are blue (#1976D2)". If you want to change headers to green, you'd have to find and replace on all 500 pages. But if page 1 says "HEADER_COLOR = blue" and every page just says "HEADER_COLOR", you change it once on page 1. That's exactly what Colors.java does.

An enum is a special type that can only be one of a fixed set of values — a flight can only be SCHEDULED, BOARDING, DEPARTED, or CANCELLED, nothing else.
Why does this file exist? Without enums, we'd use Strings like "scheduled" but someone could accidentally type "schduled" (typo) and our code would break. Enums prevent typos — the compiler catches invalid values immediately.

Employee.java

src/Employee.java
Employee is an abstract class that extends Person. An employee is a person who works at the airport and gets paid a salary. So Employee INHERITS name/identity/nationality from Person and ADDS salary on top. Both Flighter (Pilot) and modiefoun (Co-Pilot) extend Employee, because they are both employees.
Why does this file exist? This creates a chain: Person (name, identity, nationality) -> Employee (+ salary) -> Flighter (+ licenses, rokhasList) and modiefoun (+ languages, salary override). Each level adds more specific fields. Without this hierarchy, we'd have to repeat name/identity/nationality/salary in every class.

server.py is the PYTHON TCP CHAT SERVER that all chatclient instances connect to. It runs on port 5555 and handles multiple clients simultaneously using threads. When a client sends a message, the server broadcasts it to ALL connected clients (including the sender). This is the ONLY Python file in the project.
Why does this file exist? We need a server to relay messages between clients. Without a server, each client would need to know every other client's IP address (peer-to-peer), which is complex. A server is simpler: all clients connect to one central point, and the server handles distribution.
